# 报告辅助图可读性与指标均衡布局设计

## 目标

在 1920×1080 大屏报告中提高辅助图文字可读性，确保同一图内不同指标不使用相同颜色，并消除 8 个指标出现 `7+1` 孤行的问题。改动延续现有深色科技视觉，不缩小指标卡文字，不改变报告数据、指标含义或交互流程。

## 已确认的视觉规则

### 1. 图表配色

- 每张数据看板建立一份共享的指标配色表，趋势图和辅助图共用。
- 同一指标在同一张看板的不同图中保持同色。
- 同一图中的不同指标必须使用不同颜色。
- 颜色按首次出现的指标顺序分配，前两项优先使用现有青蓝与蓝绿渐变：
  1. 青蓝：`#1689DC → #2CE4F5`
  2. 蓝绿：`#19BFA0 → #42F0C7`
- 第三项起依次使用科技蓝、青绿、科技紫、科技粉、荧光黄；第八项使用主题中已有的告警珊瑚色 `#FF714D`。现有报告页预算最多承载 8 个直接指标，因此单个图内不会重复使用已占用颜色。
- 独立渲染、缩略图或缺少看板上下文时，按该图内指标出现顺序建立局部配色表，仍保证不同指标不撞色；仅单指标或旧调用继续使用稳定的指标语义映射作为回退。

### 2. 辅助图标签

- 条形图底部指标名称提升到约 17–18px 的 SVG 绘制字号，柱顶数值保持同级或略大。
- 雷达图维度名称与端点分数分别显示；端点分数使用真实值和单位，例如 `96 分`。
- 环形图中央保留主数字和指标名称；当单位为“分”时隐藏单独的“分”字，非评分单位仍可保留。
- 其他辅助图中的轴标签、直接标签和刻度文字同步提高一级，但不挤压主图，不改变指标卡字体。
- 标签不能与图形、面板边缘或证据线重叠；长标签优先换行或调整位置，不通过缩小字体解决。

### 3. 雷达图差异增强

- 端点旁显示每个维度的真实分数，不在雷达中心增加总分。
- 不固定改成 `80–100` 等局部量程，避免低分数据被裁切，也避免大范围修改刻度逻辑。
- 仅在绘制半径时围绕本组平均分做轻度差异增强：
  - 先计算所有维度平均分；
  - 将每个分数相对平均分的偏差放大约 `1.8` 倍；
  - 结果限制在合法的 `0–最大分` 范围内；
  - 最终显示的文字始终使用原始真实分数。
- 该映射保持分数排序不变，分数差距越大，端点幅度差也越大；所有分数相同时仍显示等幅雷达形状。

### 4. 指标卡布局

- 1920×1080 下最多允许 8 个指标卡单行展示。
- 8 个指标时使用一行 8 列：卡片横向略收窄、间距略收紧，现有标签和值字号保持不变。
- 长指标名称允许在卡片内部自然换行，不能通过减小字体解决。
- 9–16 个指标采用均衡两行算法：选择不超过 8 的最大列数，并保证第二行数量超过第一行的一半，避免孤立卡片。
- 典型结果：`9 → 5+4`、`10 → 6+4`、`11 → 7+4`、`12 → 7+5`、`13 → 8+5`、`16 → 8+8`。
- 现有服务端页面预算最多承载 8 个直接指标；9–16 的均衡规则用于前端防御性渲染与测试。更高密度继续由报告分页策略处理，不在当前画布内增加滚动。

## 组件与数据流

### 看板配色上下文

`DataDashboardVisual` 根据摘要指标、主图和辅助图中首次出现的指标键生成有序配色表，并通过轻量 React context 提供给原子图表。`TrendVisual` 与 `ComparisonBarsVisual` 优先读取该表；独立使用时建立图内局部有序配色，单指标或旧调用再回退到现有语义配色函数。

### 雷达图

`RadarVisual` 增加纯函数计算展示半径与端点标签位置。原始值只用于文字和无障碍数据表，增强后的值只用于 SVG 几何。

### 指标卡列数

`DataDashboardVisual` 使用独立的列数计算函数替代固定 7 列上限，并继续输出 `data-summary-columns`、`data-summary-rows`，供 CSS 和浏览器验收读取。

## 验收标准

- 1920×1080 下 8 个指标全部位于同一行，字体大小与当前版本一致，无横向滚动或卡片溢出。
- 9、10、12、16 个指标不出现第二行只有 1–3 个的突兀布局。
- 同一辅助图内所有不同指标的 `data-*` 配色标识均唯一；前两项分别为青蓝和蓝绿。
- 同一指标出现在趋势图和条形图时使用相同配色。
- 条形图底部标签、雷达维度标签和端点分数、环形图指标名称在大屏中清晰可读。
- 雷达图不显示中心总分，每个端点显示自己的真实分数；不同分数产生单调且更明显的幅度差。
- 评分环隐藏单独“分”字，非评分单位不被误删。
- 所有图形保持在辅助面板和证据线之上，字幕与证据展开行为不回归。
- 聚焦单元测试、样式合同测试、TypeScript/Vite 构建和 1920×1080 mocked Playwright 回归全部通过。

## 不在本次范围

- 不调整主标题、字幕、证据抽屉或右侧对话区结构。
- 不增加新的报告指标、业务结论或数据计算。
- 不重做整套主题，不改变已确认的科技色板。
- 不支持用户手动切换雷达量程或差异增强倍数。
